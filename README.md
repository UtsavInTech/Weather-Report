# ☁️ Weather App

A clean, modern weather application built with **HTML**, **CSS**, and **JavaScript** — featuring glassmorphic UI, dynamic weather themes, and smooth animations.

![weather-app-preview](https://img.shields.io/badge/Status-Live-brightgreen) ![HTML](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JS](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

##  The Story Behind This

I created this repo **2 years ago** when I was just starting out. Back then, I added only a few lines of code and kept things really simple — it was one of my first projects and I didn't know how to take it further.

I left it here on purpose. Every time I came back to this repo, it reminded me of **where I started**. That half-finished `index.html`, that barely-working script — it was a bookmark of my journey.

Now, **2 years later**, I finally came back and rebuilt the whole thing from scratch. Same idea, completely different execution. This project is proof that it's okay to leave things unfinished — as long as you come back and finish them. 

## ✨ Features

-  **Search any city** — get real-time weather data instantly
-  **Auto-detect location** — uses geolocation on page load
-  **Current weather** — temperature, condition, humidity & wind speed
-  **5-day forecast** — upcoming weather at a glance
-  **Dynamic themes** — background changes for sunny, cloudy, rainy, night, snow & haze
-  **Glassmorphic design** — frosted glass card with blur effects
-  **Smooth animations** — typing effect, counter, staggered cards, icon pulse

    │   └── style.css       ← All styles & animations
    ├── js/
    │   └── app.js          ← Logic, API calls & animations
    └── README.md
HTML, CSS, and JS — each in their **own folder**, clean and separated.

##  Getting Started
1. **Clone the repo**
       git clone https://github.com/UtsavInTech/Weather_report.git
2. **Open `index.html`** in your browser
       open index.html
3. **Allow location access** (optional) — or just search for any city
> No build tools, no frameworks, no npm install — just open and go.
---
##  Animations (Built with JS)
| Animation | What it does |
|-----------|-------------|
| **Fade-in** | Card slides up smoothly on first load |
| **Temp counter** | Temperature counts up from 0 to the actual value |
| **Typing effect** | City name types out letter by letter |
| **Icon pulse** | Weather icon scales in with a spring effect |
| **Staggered cards** | Forecast & stat cards appear one by one |

##  Built With
- **HTML5** — semantic, accessible markup
- **CSS3** — glassmorphism, gradients, keyframe animations, responsive design
- **Vanilla JavaScript** — no libraries, no frameworks
- **OpenWeatherMap API** — real-time weather data
